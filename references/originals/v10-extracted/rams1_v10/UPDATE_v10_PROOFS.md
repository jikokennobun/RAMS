# RAMS-1 v10.0 — 2026-10-31 差分・証明・訂正

**基準**: v9.0 (2026-10-29 JST)。**基底**: 断りない限り有界整可換剰余束の単様相拡大。`N: □1=1`, `K: □(x→y)·□x≤□y`, `M`: □は単調, `4: □x≤□□x。` 原理は公理 *集合* と原理の *成立* を混同しない。新規性は未判定。

**証拠符号**: `[P10]` このノート内に全証明を付した結果（数学者・Codex による独立検算前）; `[CM]` 計算で全元検査; `[D27]` 2026-10-27 草稿所載; `[N]` 構想・未解決; `[ERR]` 旧記録の矛盾を是正。

## R10-1. 局所吸収による Santa Claus 方程式の特徴づけ [P10]

**定義**: `SC(a): ∃p[p=□p→a]`、`FLöb(a): □(□a→a)≤□a`、`IA□: ∀x □(x·□x)=□x` とする。`IA_SC(a)` は **当該方程式の解 p** についてだけ `□(p·□p)=□p` を要求する局所条件。

**定理**（M を仮定）。`FLöb(a) ⇒ SC(a)`。さらに `SC(a)+IA_SC(a) ⇒ FLöb(a)`。従って `M+IA□` の下で全称の `SC ⇔ FLöb`。`N,K,IA□` の下ではこの同値と FLöb の既存有限連立項解定理を合わせ、`SC ⇒ gUTFPP` および `SC ⇒ gU` を得る。

**証明**: FLöb(a) の下で `s=□a→a` を置く。整性から `a≤s`。単調性で `□a≤□s`、一方 `□s≤□a` は FLöb(a) である。ゆえに `s=□s→a`。逆に SC(a) の解 p に対し `a≤p` と `p□p≤a`。単調性から `□a≤□p` かつ `□(p□p)≤□a`、局所 IA から `□p≤□a`。したがって `□p=□a`、`p=□a→a`、`□(□a→a)=□a`。□

**注意**: 当該 a だけでの局所同値から `Löb` 全体を推論しない。`gUTFPP` の帰結は `N,K` と既存 FLöb 主定理の検証を必要とする。

## R10-2. Mix を厳密に弱める [P10, CM]

`Mix□: □x≤□x·□□x` から `IA□` が従う。実際 `K⇒C: □x□y≤□(xy)` なので `□x≤□x□□x≤□(x□x)≤□x`。最後は `x□x≤x` と M から。

**厳密性の証人**: 3元 Łukasiewicz MV 鎖 `A={0,1/2,1}`, `x·y=max(0,x+y−1)`, `x→y=min(1,1−x+y)`, `□x=max(1/2,x)` は `N,K,4,IA□` を満たすが `Mix□` を満たさない。`x=0` で `□0=1/2`, `□²0=1/2`, `□0·□²0=0`。K, IA は全3×3通りの有限検査により確認（付属スクリプト）。ここでは `SC` は a=1/2 で失敗し、したがって IA の単独仮定から FLöb は従わない。

**重要な含意**（ただし「単独の原理同士の矢印」でなく公理の弱化）:

`N+K+Mix+SC ⇒ N+K+IA+SC ⇒ FLöb ⇒ gUTFPP ⇒ gUFPP`。

`IA_SC` の一般形および IA_SC と IA□ の厳密な分離は、証人の条件・変数束縛を揃えて追加検算する。[N]

## R10-3. schematic consistency と Löb／不動点原理の衝突 [P10]

`¬x=x→0`, `◇x=¬□¬x` とし、`Con_L: □0≤0`、`Con_S: ∀a(□a≤◇a)` とする。

**定理**: `N+K ⊨ Con_L ⇔ Con_S`。

**証明**: Con_S に a=0 を代入し、`¬0=1, □1=1, ¬1=0` から `□0≤0`。逆に `□0=0` なら、`a·¬a≤0`, K から得られる M,C により `□a·□¬a≤□(a¬a)≤□0=0`。剰余律より `□a≤□¬a→0=◇a`。□

**定理（正しい非存在の範囲）**: 非自明な `0≠1` の整可換剰余代数で `N+Con_L` を仮定すれば、`¬gTFPP` かつ `¬gU`。前者は **K 不要**。

**証明**: N と □0=0 から、言語 `{∧,∨,·,→,0,1,□}` の閉項が表す元は必ず 0 または 1（構文帰納法）。ガード付き項 `t(p)=¬□p` に対し `t(0)=1`, `t(1)=0`。従って閉項 s による `s=t(s)` は不可能で、gTFPP は成立しない。また `p=□p` は 0,1 という二つの異なる解を持つため gU も成立しない。□

**さらに**: 非自明な N+Con_L と FLöb は両立しない。x=0 を FLöb に代入すると `□(□0→0)=□1=1≤□0=0` となる。Con_L と `IA_SC(0)+SC(0)` も両立しない（R10-1 の点別証明）。

**反例・対照**: 標準 Łukasiewicz MV 区間 `[0,1]` に `□=id` を置くと `N,K,4,CP,Con_S,SC,FPP` が成立する。SC の解は `p=(1+a)/2`、一方 `□p=p` は全元を解とするので gU は失敗する。**gTFPP も失敗する**（定理による）。従来の「Con_S+SC+gTFPP がこのモデルで成立」という主張は撤回する。[ERR]

**非自明な研究課題**: `Con_S` を gTFPP と両立させるなら、(i) N を外す、(ii) `Con_S` の定義自体を変える、(iii) p-free な閉項として解を要求しない弱い選択原理を使う、のいずれかが必要。これらは同じ命題の反例にはならない。

## R10-4. SC は F_{1,1} を含意しない：旧草稿の具体証人を再固定 [D27; 直接計算]

正の無限小 ε を持つ `Q(ε)` の順序で `R_−=Q[ε,(1+ε)^{−1}]`、`A=R_−∩[0,1]` の Łukasiewicz MV 鎖に `□x=1−ε+εx` を置く。全 `a∈A` に対して `p=(a+ε)/(1+ε)` が `p=□p→a` を満たし、従って SC は成立する。一方 `p=a·□p` に `a=1/2` を代入すると実区間での唯一解は `p=(1/2−ε)/(1−ε)` である。これは ε=1 に極を持ち、`R_−` には属さない。ゆえに `SC⇏SC^+`、特に `SC⇏F_{1,1}`。

**注意**: 2026-10-29〜30 の対話には `SC⇒F_{1,1}` を再び「未決着」と呼ぶ記録があるが、**一般 bicRAMS に関する命題ならこの具体証人が否定する**。追加公理を明示した別の問いであれば、その背景クラスを付して再登録する。

## R10-5. gTFPP の保存性と gTFPP⇒gU の位置 [E9-1 / N]

v9 の定理 `gTFPP(A) ⇔ HSP(A)⊨gFPP ⇔ SP(A)⊨gFPP` を保持。これは一般 gTFPP⇒gU の証明ではない。反例候補 `gTFPP∧¬gU` は非自明 `N+□0=0` の構造では作れない（R10-3）。`IA□+SC` のクラスでも作れない（R10-1）。よって探すなら `□0≠0` かつ IA 局所条件を破るモデルから出発すること。

**その他の検討**: 線形順序以外の Lindenbaum／自由代数、CP の有無、Mix を弱める局所吸収、代数的な有限項選択、項による構成と高々一意性の分離。有限 Ł 鎖およびアフィン MV 族の反例排除は従来の研究ノートにあるが、全係数の分類定理としては未確定。[N]

## R10-6. 距離・連続性・項縮小性：要件の階層 [P10]

`TermCont(τ)`（全基本演算が積位相で連続）ならガード付き項も連続。ただし `GuardCont_p(τ)`（パラメータを固定したとき、**未知変数 p に関する**全ガード付き項写像が連続）から `TermCont(τ)` は従わない。

**証人**: `[0,1]` の Gödel（min）積と Gödel 残余 `x→y=1 (x≤y), =y (x>y)` に通常の実数位相を入れ、`□x=1` とする。すべてのガード付き項は p に独立となるから `GuardCont_p` が成立する。しかし剰余 `→` は対角上 `(t,t)` (`0<t<1`) で不連続。N,K,4 も満たす。

**区別**: これは全引数に関するガード付き項の *共同連続性* の反例ではない。`□=1` としても、パラメータとして出現する `→` の不連続性は残る。

`GMC`（全ガード付き項が同一完備距離で適切に縮小）／`AMC`（□縮小かつ非様相基本演算すべて max-非拡大）／`MC`（□のみ縮小）を別項にする。`AMC⇒GMC⇒gUFPP` はガード項が各有限出現で q-縮小するという意味で成立。逆は一般に未検証。`AMC⇒uAMC` の過去の超距離化スケッチは証明が一致しておらず、正式な成立矢印には **入れない**。

## R10-7. 完備束・超限反復・scattered locale [N / 標準事実]

完備束で単調な □ に対する超限反復 `b_0=0, b_{α+1}=□b_α, b_λ=∨_{β<λ}b_β` は最小不動点へ停止する。N の下で `Löb` が成立することは「□ の唯一の不動点が 1」という主張より一般に強いかどうか、超限停止との関係は証明の仮定（単調性・4・complete lattice・軌道連続性）を付けて扱う。Cantor–Bendixson 派生作用素に由来する scattered 空間は、閉包順序数を具体化する意味論的モデルとして別扱い。

## R10-8. 算術的・資源的モデル、G2-Zoo への接続 [N]

非古典算術の Lindenbaum 代数での N,K,4,FLöb や対角化の妥当範囲を検討する。非古典算術からの `gFPP` は得られても、**同じ言語のパラメータ項による一様解** `gTFPP` が従うと即断しない。`Con_S/Con_L` は `Con_H,Con_IG,Con_EG,non-Ros` などの異なる言語・量化を必要とする整合性概念から区別する。

## R10-9. 明示的な訂正・撤回 [ERR]

1. `Con_S + SC + gTFPP` を通常 MV 言語の `□=id` で実現できるという過去の主張を撤回（R10-3）。
2. `SC⇒F_{1,1}` を**無条件で未決着**とする記録を訂正。一般 bicRAMS では反例あり。特定の追加仮定下なら別問題（R10-4）。
3. `AMC⇒uAMC` を確定済みとする 10月29日の一部の会話記録について、整合した自足的証明を現状確認できない。v9 基準どおり「未検証」に保つ。
4. `Mix + SC ⇔ ...` は Mix 単独で各原理が成立する意味ではない。
5. `gTFPP` と `gU` を混同しない。「項による選択」と「全解の一意性」は異なる。
6. 以前の有限・可算連立系の分離 V22–V25 の証明は独立検算されていないので、証明済み数に算入しない。
